# 🚀 Промышленный Мини-Проект Недели 2: Enterprise Multi-Format Hybrid RAG Engine for Financial & Legal Contracts

## 🎯 Бизнес-контекст и Отраслевая задача
Банкам, страховым и юридическим компаниям требуется RAG-система для анализа тысяч сложных уставных документов, финансовых отчётов и контрактов (содержащих таблицы, статьи, мелкие формулировки и номера спец-пунктов). Обычный векторный поиск теряет статьи контрактов и галлюцинирует. Вам нужно построить поисковый движок промышленного уровня с гибридным поиском, алгоритмом слияния RRF, переранжированием через Cross-Encoder и автоматическим расчетом метрик точности поиска.

---

## 🔬 Что доказывает выполнение этого проекта:
1. Вы умеете правильно структурировать неструктурированные корпоративные документы с сохранением метаданных (раздел, страница, номер пункта).
2. Вы понимаете, почему векторный поиск уступает гибридному (Dense + Sparse BM25), и умеете настраивать алгоритм слияния **Reciprocal Rank Fusion (RRF)**.
3. Вы понимаете разницу между Bi-Encoders и Cross-Encoders и умеете оптимизировать Latency за счет двухстадийного поиска (Retrieval Top-30 -> Reranking Top-5).
4. Вы умеете математически доказывать качество поиска через метрики **Hit Rate@K** и **MRR (Mean Reciprocal Rank)**.

---

## 📋 Чек-лист функционала решения:
- [ ] Семантический парсинг PDF/Markdown документов с сохранением структурных метаданных.
- [ ] Параллельная индексация в векторную базу Qdrant/LanceDB (Dense BGE-Embeddings) и индекс BM25 (Sparse).
- [ ] Имплементация алгоритма Reciprocal Rank Fusion (RRF) с коэффициентом $k=60$.
- [ ] Двухстадийный инференс: Извлечение Top-30 кандидатов -> Переранжирование через Cross-Encoder (`bge-reranker-base`) до Top-5.
- [ ] Модуль фильтрации галлюцинаций (Grounding Checker / Citation Verifier) — проверка наличия факта в контексте перед генерацией.
- [ ] Модуль оценки качества: Расчёт Hit Rate@5 и MRR на наборе из 20 контрольных вопросов бизнеса.
