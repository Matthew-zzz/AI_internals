# 🚀 Промышленный Мини-Проект Недели 4: Enterprise QLoRA Fine-Tuning & MLOps CI/CD Evaluation Pipeline for Customer Support Intent Classification

## 🎯 Бизнес-контекст и Отраслевая задача
Финтех-компании требуется автоматически классифицировать и маршрутизировать 100 000 ежедневных сложных обращений клиентов по 50 специфическим категориям финансовой безопасности и операций. Использовать внешний OpenAI API запрещено политикой безопасности (GDPR/Compliance). Вам нужно дообучить маленькую открытую модель (Qwen 2.5 3B / Llama 3.2 3B) с помощью QLoRA на специфических данных компании, развернуть её на собственном GPU-сервере в движке **vLLM** и построить автоматизированный CI/CD Eval Pipeline для сравнения качества дообученной модели против базовых систем.

---

## 🔬 Что доказывает выполнение этого проекта:
1. Вы умеете самостоятельно собирать, чистить и форматировать датасеты под задачи Fine-Tuning в формат ChatML.
2. Вы понимаете математику LoRA (низкоранговые матрицы адаптеров $W = W_0 + B \times A$, ранг $R$, масштабирование $\alpha$) и QLoRA (4-bit NF4 квантование, Double Quantization, Paged Optimizers).
3. Вы умеете оптимизировать инференс моделей в продакшене через **vLLM** (PagedAttention, Continuous Batching, Tensor Parallelism).
4. Вы умеете проектировать систему автоматического тестирования качества ИИ (Evals) по метрикам Accuracy, F1-Score, Latency и LLM-as-a-Judge.

---

## 📋 Чек-лист функционала решения:
- [ ] Модуль подготовки данных: генерация и валидация 500+ диалоговых примеров в формате ChatML с разделением на train/test (80/20).
- [ ] Обучающий скрипт QLoRA (на базе Unsloth / PEFT + TRL `SFTTrainer`): квантование 4-bit NF4, настройка LoraConfig ($r=16, \alpha=32$), сохранение весов.
- [ ] Деплой инференса на vLLM с непрерывным батчингом (Continuous Batching) и подключением обученных адаптеров LoRA.
- [ ] CI/CD Eval Pipeline: автоматический прогон 100 контрольных тестов через Baseline модель (до дообучения) и Fine-Tuned модель.
- [ ] Сводный аналитический отчёт: сравнение Accuracy, F1-Score, времени отклика (Latency ms) и стоимости 1000 запросов.
