# 🚀 Промышленный Мини-Проект Недели 3: Autonomous Multi-Step Database & Analytics Agent with Constrained Decoding (Pydantic v2 + SSE Streaming)

## 🎯 Бизнес-контекст и Отраслевая задача
Крупному e-commerce сервису требуется автономный ИИ-аналитик, который подключается к продуктовой базе данных (клиенты, заказы, транзакции, возвраты) и отвечает на бизнес-вопросы руководства ("Найди топ-10 клиентов с максимальным падением среднего чека за прошлый месяц, сгенерируй для них спец-предложения и выдай структурированный JSON"). 

Агент должен работать **без сбоев бэкенда**, использовать грамматическое ограничение вывода (Structured Outputs), сам отлавливать и чинить ошибки SQL-запросов и передавать ход мыслей пользователя в реальном времени по SSE.

---

## 🔬 Что доказывает выполнение этого проекта:
1. Вы умеете принуждать вероятностную модель генерировать 100% валидный JSON через Pydantic v2 и грамматики вывода (Constrained Decoding / Logit Bias).
2. Вы умеете проектировать графы состояний (State Machines / LangGraph) с контролируемыми переходами между шагами: `Inspection -> Query Plan -> Execution -> Self-Correction Loop -> Final Synthesis`.
3. Вы понимаете безопасность: Изоляция SQL-запросов (только READ-ONLY транзакции, отсечение `DROP/DELETE`).
4. Вы умеете проектировать современный асинхронный UX со стримингом цепочки мыслей агента по Server-Sent Events (SSE).

---

## 📋 Чек-лист функционала решения:
- [ ] Определение строгих Pydantic v2 схем для всех шагов агента (Plan, SQLQuery, ErrorAnalysis, FinalAnalyticsReport).
- [ ] Графовый оркестратор состояний (State Machine) с памятью диалога и истории мыслей.
- [ ] Изолированный SQL-исполнитель с ограниченными правами (Read-Only SQLite/PostgreSQL).
- [ ] Цикл самоисправления (Self-Correction Loop): при возникновении SQL-ошибки агент формирует Pydantic-объект с разбором ошибки и генерирует исправленный SQL (до 3 попыток).
- [ ] FastAPI веб-сервер с асинхронной трансляцией каждого шага рассуждения агента (Streaming thought graph по SSE).
- [ ] Интеграционные тесты на обработку некорректных или невыполнимых бизнес-вопросов.
