# 📅 Неделя 3: Автономные Агенты и Детерминированный контроль (Structured Outputs)

## 🎯 Цели недели
Принудить вероятностную модель выходить за пределы генерации текста и выполнять бизнес-логику строго по заданной Pydantic-схеме с обработкой ошибок.

---

## 📋 Чек-лист темы
- [ ] Паттерны агентов (ReAct: Reasoning + Acting)
- [ ] Грамматическое зажатие ответа (Outlines / Instructor / Pydantic v2)
- [ ] Построение State Machine агента (LangGraph / чистый Python)
- [ ] Потоковый инференс размышлений агента через Server-Sent Events (SSE)

---

## 📁 Файлы проекта

1. **`pydantic_schemas.py`** — Объявление Pydantic v2 схем для генерации валидного JSON.
2. **`sql_agent.py`** — Автономный SQL-агент с циклом самоисправления (Self-Correction Loop).
3. **`streaming_server.py`** — FastAPI сервер с трансляцией цепочки мыслей агента по SSE.
